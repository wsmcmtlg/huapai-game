# 第一部分：规则

## 1. 牌组

- **22 个字**：上 大 人 可 知 礼 三 五 七 化 千 孔 己 二 四 六 八 十 子 土 乙 九
- **每字 5 张**，另加 **2 张赖子**，共 **112 张**
- 精牌（三、五、七、乙、九）每字 2 张**花**（大写：叁伍柒壹玖）+ 3 张**皮**（小写）
- 非精牌 5 张全为皮
- 红字：上大人可知礼、三五七；黑字：其余
- **赖子只能通配精牌三五七**，不能通配乙九

## 2. 顺子（共 14 种）

固定 6 种：上大人、可知礼、化三千、孔乙己、七十土、八九子
数字 8 种：乙二三、二三四、三四五、四五六、五六七、六七八、七八九、八九十

## 3. 牌型

| 牌型 | 张数 | 说明 |
|---|---|---|
| 坎 | 3 | 手中三张同字（自由牌） |
| 顺 | 3 | 上表 14 种 |
| 碰 | 3 | 手中 2 张 + 旁家打出 1 张（明牌，**限两次**） |
| 招牌 | 4 | 坎 + 旁家打出同字（**招是动作，招牌是牌型**；明牌固定） |
| 扎 | 4 | 手中 4 张同字（暗牌，**可用赖凑**） |
| 穿 | 5 | 扎 + 第 5 张（摸到/手中第 5 张/赖通配） |
| 泛 | 5 | 招牌 + 摸第 5 张，或 扎 + 旁家打出第 5 张（明牌固定） |
| 眼 | 2 | 对子 或 口（半顺两张） |
| **摞** | 1 | 8 圆句 + 1 单张待圆的听牌结构（8+1 型） |

## 4. 流程

- 3 人：庄家 + 下家 + 上家，**逆时针**（唯一例外：发牌后确定是否扎牌是顺时针）
- 庄家 26 张，旁家各 25 张；牌墙 36 张
- 胡牌方式：**捉铳**（吃/碰统牌成胡）或 **自摸**
- **胡数门槛 17 胡**；牌墙空即流局（不计分）

## 5. 关键限制

| 规则 | 说明 |
|---|---|
| 吃统 = 捉铳 | **只有"吃进这张牌立刻能胡"才允许吃**，不存在"吃后听牌" |
| 碰限两次 | 第三次碰牌**必须直接胡牌** |
| 扎/穿可自选 | 扎在手中、旁家不知 → 只要凑够张数，**扎哪几张、赖怎么分由玩家定** |
| 招牌/泛固定 | 明牌、旁家已知 → 不可再拆 |
| 过牌记录 | 放弃的碰/招/胡，到**下次摸牌前**失效 |

## 6. 计胡

| 牌型 | 非精牌 | 含精牌 |
|---|---|---|
| 顺 | 0（红顺 上大人/可知礼 = 1） | 查表/逐张 |
| 坎 | 红 2 / 黑 1 | 查表 |
| 碰 | 红 1 / 黑 0 | 逐张 |
| 招/扎 | 红 4 / 黑 2 | 共用 zhao 表 |
| 穿/泛 | 红 8 / 黑 4 | 共用 chuan 表 |
| 眼（对子/口） | 0 | 逐张 |
| 摞 | 按普通规则（如二摞捉铳三 = 1 胡，三为主精 = 2 胡） | 同左 |

- 精牌：红精 花+2/皮+1；黑精 花+1/皮 0；赖 +2
- **主精（三五七一选定）出现在任何牌型都翻倍**
- 查表值即最终值（"小概率组合奖励"只是对查表的解释）
- 结算：17-21 胡 = 档 0，每 +5 胡 +1 档；捉铳赢 +(5+2t)、自摸 +(6+2t)、放统 −(3+t)、未放统 −(2+t)

# 第二部分：AI 与测量

## 7. 四级强度（校准桌：目标 AI 坐庄 vs 2×高手陪练，seed 20261027）

| 等级 | 局数 | 胡牌率 | 95%CI | 原目标 |
|---|---|---|---|---|
| L0 菜鸟 | 120 | 8.3% | 4.6~14.7 | 5~15% ✅ |
| L1 高手 | 120 | 24.2% | 17.4~32.6 | 15~35% ✅ |
| L2 大师 | 120 | 29.2% | 21.8~37.8 | 35~65% |
| L3 老千 | 150 | 35.3% | 28.1~43.3 | 65~85% |

## 8. 为什么 L2/L3 达不到原目标

**荒庄率是唯一瓶颈**：

| 桌 | 荒庄率 |
|---|---|
| L3 桌 | 55% |
| L2 桌 | 57% |

三家胡牌率之和 = 100% − 荒庄率。L3 桌三家合计只有 45%，而目标是老千一家就 65%+。

**荒庄为什么压不下去**（五组实验验证）：

| 实验 | 结果 |
|---|---|
| 强制旁家碰牌 | 更差（36.7% vs 41.7%） |
| 关掉"做大不做小" | 无变化（噪声内） |
| 缩短起手牌（墙变长） | 更差（荒庄 78%） |
| 碰次上限 2→3→不限 | 只 +5pp；3 与不限结果完全相同（一局碰不到 3 次） |
| **额外补墙牌** | **有效**：+12→荒庄 45%、+24→荒庄 27% |

结论：**荒庄 ~55% 是"112 张牌 / 起手 26·25·25 / 每回合换 1 张 / 每家约 12 摸"这套规则的物理上限**。

## 9. 要达标需要什么

| 改法 | 荒庄 | L3 老千 |
|---|---|---|
| 现状 112 张 | 58% | 35% |
| 墙 +12（124 张） | 45% | 52% |
| 墙 +24（136 张） | 27% | 60% |
| 墙 +36（148 张，外推） | ~20% | 可进 65%+ |

# 第三部分：交付与验证

## 10. 玩法

双击 `启动游戏.bat`（或 `启动游戏_PWA.bat` 走本地服务器模式）。

## 11. 已实现的体验机制

| 机制 | 说明 |
|---|---|
| 连败放水 | 玩家连输 ≥2 局后，旁家出牌随机度每局 +5%（上限 +15%），赢即清零 |
| 思考节奏 | L0 380 / L1 520 / L2 680 / L3 860 ms + 抖动 |
| 新手引导 | 首次进入讲清"吃统=捉铳 / 碰限两次 / 扎穿可自选" |
| 听牌提示 | 显示所有听口 + 每个听口剩余张数，并带呼吸动画 |
| 听牌提示音 | 刚进听响一声（去重，同一状态只响一次） |
| 大牌型高光 | 结算时穿/泛/扎/招牌及 ≥8 胡的牌型行金色高亮 + ★ |
| 视角润色 | 按钮/手牌悬停抬起、结算面板进场动画、移动端按钮加大、支持减少动效 |

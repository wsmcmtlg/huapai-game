# 手动修复手册：花牌游戏启动（LHP）

> 一句话：**双击 `启动游戏.bat` 即可**，不再需要 Python。
> 本手册覆盖所有常见启动故障的自查与修复步骤。

---

## 一、正常启动

1. 双击 `C:\Users\Administrator\Desktop\LHP\启动游戏.bat`
2. 弹出黑窗口（标题「湖北花牌 - 本地启动」），显示：
   ```
   URL: http://127.0.0.1:8765/step5-hu.html
   ```
3. 浏览器自动打开游戏页

> 黑窗口不要关，关掉 = 停止服务器。

---

## 二、如果还是打不开：按顺序自查

### ① 端口被占用
`serve.ps1` 会自动换端口（8765 → 8766 → …）。看黑窗口里 `URL:` 那行的实际端口，用浏览器手动打开那个地址即可。

手动查占用 / 释放：
```bat
netstat -ano | findstr :8765
taskkill /F /PID <上一步的进程号>
```

### ② 防火墙拦截
本地回环 127.0.0.1 一般不受防火墙限制。若黑窗口报 `cannot bind port`，多为端口占用或杀软拦截。可临时关闭第三方杀软再试。

### ③ 浏览器缓存 / Service Worker 缓存
游戏是 PWA，旧版 Service Worker 可能缓存了旧页面。解决：
- 强刷：**Ctrl + Shift + R**
- 或打开开发者工具（F12）→ Application → Service Workers → Unregister，再刷新
- 仓库已把缓存版本升到 `huapa-v6`，正常会自动更新

### ④ PowerShell 被组策略禁用
若黑窗口一闪而过或提示"在此系统上禁止运行脚本"：
```bat
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\Administrator\Desktop\LHP\serve.ps1"
```
（我们已在 .bat 里带了 `-ExecutionPolicy Bypass`，一般无需手动处理）

## 三、不用启动器，手动起服务器（兜底三选一）

**方式 A：PowerShell（推荐，零依赖）**
```powershell
cd C:\Users\Administrator\Desktop\LHP
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
```

**方式 B：Python（本机 WPS 灵犀自带，路径固定）**
```bat
"C:\Users\Administrator\AppData\Roaming\WPS 灵犀\python-env\python.exe" -m http.server 8765 --bind 127.0.0.1
```
然后浏览器打开 `http://127.0.0.1:8765/step5-hu.html`

**方式 C：Node（本机 WPS 灵犀自带）**
```bat
"C:\Users\Administrator\AppData\Roaming\WPS 灵犀\portable-node\node-v24.17.0-win-x64\node.exe" -e "require('http').createServer((q,s)=>{let f=require('fs');let p=__dirname+q.url.split('?')[0].split('/').join('\\');if(p==='\\')p='\\step5-hu.html';f.readFile(p,(e,d)=>{if(e){s.writeHead(404);s.end()}else{s.writeHead(200,{'Content-Type':p.endsWith('.html')?'text/html;charset=utf-8':'application/octet-stream'});s.end(d)}})}).listen(8765,'127.0.0.1',()=>console.log('http://127.0.0.1:8765/step5-hu.html'))"
```
> 注意：方式 C 需在该目录下执行，且图片/音频也能通过 application/octet-stream 正常加载。

## 四、高级：局域网 / 手机访问

默认只绑定本机 127.0.0.1（最安全）。若要让同网段手机访问，需要管理员权限添加 URL ACL：

```bat
:: 以管理员身份运行
netsh http add urlacl url=http://+:8765/ user=Everyone
```
然后在 `serve.ps1` 用 `-Bind 0.0.0.0` 启动，用本机局域网 IP 访问（`ipconfig` 查 IPv4）。

> 出于安全，日常建议保持 127.0.0.1。

# 节奏与体感设计（2026-11-06）

## 一、AI 思考延迟分级（本轮落地）

**思路**：用"想多久"表达强弱，比改数值更有体感——高手出牌会让人等，菜鸟几乎不假思索。

| 等级 | 基础延迟 | 说明 |
|---|---|---|
| L0 菜鸟 | 380ms | 随手打，几乎不等 |
| L1 高手 | 520ms | 略作思量 |
| L2 大师 | 680ms | 明显在算 |
| L3 老千 | 860ms | 慢条斯理、压迫感 |

另加 0~120ms 随机抖动，避免机械节奏；可用 `G._thinkDelay[level]` 覆盖。

**安全性**：延迟只影响 UI 观感，不参与任何判定；测量器的 `setTimeout` 是同步队列，因此**不影响胜率测量**（40 局复跑结果与基线一致）。

## 二、为什么不做"老千作弊式拖延"

有人以为"想得久=更聪明"，但超过 1.2 秒就会让玩家觉得卡顿。860ms 是体感与压迫感的平衡点：既让人觉得"这货在算我"，又不会焦躁。

## 三、与粘性放水的配合

- 连败时旁家出牌 ε 上调（最多 +15%）→ 出牌更"随意"
- 同时延迟不变 → 玩家仍会觉得对手在思考（不暴露放水）
- 这是"呼吸感"的关键：**放水在决策质量上，不在节奏上**

## 四、后续可做的体感项

1. **高光特写**：穿/泛/精牌坎成立时，牌面短暂放大 + 专属音效
2. **听牌提示音**：进听那一刻给一声轻响（不打断操作）
3. **危险提示**：旁家连摸三张后，桌面轻微提示（暗示对方在做牌）
4. **结算节奏**：胡牌后先亮牌型 600ms，再出分数，避免一次性堆满
